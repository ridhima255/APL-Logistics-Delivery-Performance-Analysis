# Delivery Performance, Delay Risk, and Logistics Efficiency Analysis in Global Supply Chain Operations

This project presents an interactive logistics analytics dashboard developed using **Python, Pandas, Streamlit, Plotly, Matplotlib, and Seaborn** to evaluate delivery performance, identify delay risks, and analyze logistics efficiency across the supply chain. The dashboard transforms raw shipping data into meaningful business insights by calculating lead time, monitoring delayed shipments, comparing shipping modes, evaluating regional performance, and visualizing key logistics metrics through interactive charts, KPI cards, geographic analysis, trend monitoring, and dynamic filters. It enables logistics managers and business stakeholders to make data-driven decisions, improve operational efficiency, reduce delivery delays, identify bottlenecks, and optimize overall supply chain performance through an intuitive and interactive analytics platform.
